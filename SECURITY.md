# Security policy

## Supported versions

The latest commit on `main` of `arrowlane` is the supported version. Older commits
are not supported.

## Reporting a vulnerability

Report privately through GitHub. Open the repository's Security tab and choose
Report a vulnerability. Do not open a public issue.

Include the affected commit, the steps to reproduce, and the impact.

We review reports on a best-effort basis. There is no service-level agreement.

## Scope

This repository is a demonstration project. The demo binds to loopback, holds no
production data, and uses documented demo credentials. Report a leaked real
credential with the same private route.
